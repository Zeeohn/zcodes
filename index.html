How we build

  • Runs on Atlassian. Our apps run on Atlassian's infrastructure and make no outbound network calls. Your data stays in your Atlassian site.
  • Verified inputs. Every incoming webhook is checked (HMAC signatures or a private token) before anything happens.
  • Minutes to set up. Each app has a built-in test button so you can see it working before you rely on it.
